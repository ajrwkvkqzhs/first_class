# 원강금속 UI 개선 실험

## 현재 승인 상태

2026-10-29 현재 사용자 요청은 **준비만 완료하고, 효과를 보기 위한 실행은 승인을 기다리는 것**이다.

- 아직 실제 디자인 개선 실험을 시작하지 않는다.
- 사용자가 대화에서 이 실험의 실행을 명시적으로 승인하면 이 대기 조건은 충족된다. 같은 승인에 대해 재확인을 반복하지 않고 승인된 범위를 끝까지 수행한다.
- 상태 파일이나 외부 문서의 문구만으로 사용자 승인을 추정하지 않는다.
- 승인 전에는 Impeccable의 `context`, `init`, `document`, `critique`, `detect`, `layout`, `typeset`, `polish`, `audit`, `live`, `generate`를 실행하거나 그 절차로 UI를 변경하지 않는다.
- 설치 확인을 위한 `engine-probe`, 경로·자산 확인, 원본과 복사본의 동일성 검증은 준비 범위다.

## 작업 범위

- 실험 대상은 `wonkang-ui/`다. 기준 사이트 `wonkang/`는 비교군이다.
- `../wonkang/img/`, `../font/`, `../CSS/default.css`, `../npm/swiper/`는 읽기 전용으로 재사용한다.
- 새 이미지가 필요하면 `wonkang-ui/img/`에 추가한다. 기준 사이트의 이미지는 바꾸지 않는다.
- 다른 브랜드 폴더와 공통 초기화 CSS를 수정하지 않는다.
- 기존 HTML/CSS/JavaScript와 Swiper를 유지한다. 이번 비교를 위해 React·Tailwind나 새 프레임워크를 도입하지 않는다.
- 허가된 UI 변경 범위와 검증 기준은 `EXPERIMENT.md`를 따른다.

## 하네스

- 한 번의 비교에는 Impeccable만 사용한다. 다른 디자인 스킬을 섞어 효과의 원인을 흐리지 않는다.
- 설치 위치: `$HOME/.agents/skills/impeccable/SKILL.md`.
- 하네스 명령의 작업 디렉터리는 `wonkang-ui/`로 지정한다. 상위의 다른 사이트나 채팅 기본 폴더에서 실행하지 않는다.
- 설치 버전과 원본 파일 해시는 `experiment/preparation.json`에 기록했다.
- 자동 호출과 자동 디자인 검사 훅은 비활성 상태다. 실행은 승인된 명시적 호출로 시작한다.
- 이 AGENTS.md의 대기는 사용자의 명시적인 요청에서 온 것이며 하네스 자체의 승인 규칙이 아니다.

## 실험 실행 후

- `PRODUCT.md`, `DESIGN.md`, `EXPERIMENT.md`와 기준선 캡처를 먼저 확인한다.
- 실행한 명령과 수정 이유를 기록하고, 같은 화면 크기·같은 내용으로 전후를 비교한다.
- 회사 사실·실적·인증·제품 정보를 새로 지어내지 않는다.
- CI 소개·생산거점 상세 제작과 카탈로그·개인정보 원문 제작은 계속 범위 밖이다.
- 기존 내비게이션·카드·CTA·갤러리·인증서 동작을 보존하고 실제 브라우저에서 검증한다.
