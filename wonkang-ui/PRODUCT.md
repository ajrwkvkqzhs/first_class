# 원강금속 UI 개선판 제품 맥락

이 문서는 준비 단계에서 기존 사이트와 사용자 요청으로 확인한 맥락이다. 하네스 실행 결과는 아니다.

## 사이트의 역할

원강금속의 주조 기술·사업 분야·제품·공정·품질 증빙을 소개하고 문의로 연결하는 한국어 기업 사이트다. 이 표면의 모드는 Persuade다.

첫 실험은 기존 자산을 사용하는 code-led 개선으로 진행한다. 새 이미지 생성이나 새로운 콘텐츠 제작은 이번 하네스 효과 비교에 섞지 않는다.

주요 방문자는 산업용 금속 부품을 검토하는 구매·설계·품질 담당자라는 가정으로 시작한다. 실제 방문자 조사 자료는 제공되지 않았으므로 이를 검증된 고객 통계로 표현하지 않는다.

## 방문자가 해야 하는 일

1. 주조사업·특수합금강·스테인리스 주강의 차이를 파악한다.
2. 펌프·밸브·산업기계부품과 관련 공정·설비를 살펴본다.
3. 인증과 협력사 등 현재 제공된 증빙을 확인한다.
4. 이메일·전화로 문의하거나 사업장 정보를 찾는다.

## 유지해야 할 내용과 기능

- 현재 제공된 회사 정보·주소·연락처·실적·인증·협력사·제품명.
- 히어로 전환, 카드 번호 이동과 겹침, 제품 CTA, 좌우 공정 사진 등장, 인증서 선택과 확대.
- 아래로 스크롤하면 숨고 위로 스크롤하거나 상단에 마우스를 가져가면 나타나는 내비게이션.
- 히어로 안의 투명 헤더와 히어로 경계 이후의 밝은 헤더.
- 키보드 접근, 터치에서 CTA 표시, 모션 감소 설정, 작은 화면의 메뉴 내부 스크롤.

## 사용자 제약

- 기존 사이트를 남기고 인덱스의 `UI 개선판`에서 별도 비교한다.
- 이번 턴에는 준비만 하고, 실제 디자인 개선 실행은 사용자 승인을 기다린다.
- CI 소개·생산거점은 임시 페이지다. 전용 내용은 만들지 않는다.
- 카탈로그 원본과 정식 개인정보 취급방침은 제공되지 않았다.
- 실제 내용이나 근거 없는 장점·수치·인증을 새로 생성하지 않는다.
