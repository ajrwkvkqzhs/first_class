| 후보 | 별 수 | 검토 결과 |
| --- | ---: | --- |
| [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | 142,191 | 스타일·색상·폰트·스택 자료와 디자인 시스템 생성에 강점. 대안으로 남김 |

별 수는 인지도 참고 자료이며 실제 디자인 효과를 입증하는 점수가 아니다.

## 설치와 실행의 구분

준비한 것:

- Codex 사용자 스킬 폴더에 Impeccable 4.8.0 설치.
- 검토한 소스 커밋으로 고정: `5e745ace7e151feb2a93d360d0281fe39448b857`.
- 공식 Windows 엔진 0.1.18을 내려받고 배포 체크섬과 SHA-256 대조.
- 엔진 버전 응답 확인: `impeccable-engine 0.1.18`.
- 자동 호출 비활성화. 자동 디자인 검사 훅은 설치하지 않음.
- 원본 보존, 독립 HTML/CSS/JS, 읽기 전용 자산 재사용, 맥락 문서와 비교 기준.

승인 후 실행할 것:

- Impeccable 맥락 로딩과 실제 UI 비평·개선·검증.
- 디자인 탐지기 실행과 전후 결과 기록.
- 개선 결과의 브라우저 확인과 공개 사이트 반영.

설치된 스킬은 다음 턴부터 사용할 수 있다. 표시되지 않으면 Codex를 다시 시작한다. 공식 [Codex 스킬 문서](https://learn.chatgpt.com/docs/build-skills)와 [Impeccable 설치 문서](https://impeccable.style/tutorials/getting-started/)를 참고한다.

## 승인 후 사용할 명령

아래는 **Codex 채팅에 넣을 요청문**이다. 지금 실행하지 않는다.

```text
$impeccable

원강금속 UI 개선 실험을 실행한다.
대상은 C:/Users/hi/Desktop/first_class/wonkang-ui/ 이다.
하네스 명령의 작업 디렉터리도 이 폴더로 지정하라.
AGENTS.md, PRODUCT.md, DESIGN.md, EXPERIMENT.md와 준비 기록을 먼저 읽어라.
기준 사이트 wonkang/는 보존하고 UI 개선판만 현업에서 사용할 만한 기업 사이트로 다듬어라.
critique로 개선 우선순위를 정한 뒤 layout·typeset으로 구조와 정보 위계를 정리하고,
polish와 audit로 마감·반응형·접근성·기능을 확인하라.
회사 사실과 기존 인터랙션을 보존하고 같은 내용·화면 크기의 전후 캡처로 비교하라.
원본 파일 해시가 유지되는지 확인하고, 무엇이 좋아졌는지와 남은 문제를 한국어로 보고하라.
```

이 명령의 실행 대기는 사용자가 직접 요청한 조건이다. 설치 확인이나 준비 검증이 이 명령의 실행 승인을 대신하지 않는다.

## 평가 기준

| 기준 | 비교할 내용 |
| --- | --- |
| 정보 위계 | 첫 화면에서 회사가 하는 일과 문의·탐색 경로가 쉽게 읽히는가 |
| 기업 사이트 완성도 | 글·사진·여백·정렬·색상이 일관되고 산업 분야에 어울리는가 |
| 카드와 CTA | 다음 내용과 동작이 명확하며 실제 조작이 가능한가 |
| 반응형 | 작은 화면에서 제목·메뉴·버튼·사진이 겹치거나 잘리지 않는가 |
| 기존 기능 보존 | 내비게이션, 카드, CTA, 갤러리, 인증서, 연락처가 계속 작동하는가 |
| 내용 보존 | 회사 사실·수치·인증·제품이 유지되며 근거 없는 내용이 추가되지 않았는가 |

별 수나 임의의 심미 점수 대신 같은 조건의 전후 화면과 조작 결과를 제시한다. 자동 탐지 결과와 사람의 시각적 평가는 구분해 기록한다.

## 비교 조건

- 1920×1080, 1440×900, 390×844 화면을 기본으로 사용한다.
- 동일 콘텐츠·동일 자산·동일 브라우저·동일 모션 설정에서 비교한다.
- 하네스 실행 전의 캡처와 원본 파일 해시를 기준선으로 보존한다.
- 큰 이미지 교체·회사 문구 변경·새 기능 추가처럼 별도 변수가 생기면 그 영향을 보고한다.
- 준비 검증은 링크·자산·기능·복사본 동일성만 확인한다. 하네스의 디자인 효과를 측정하는 작업은 실행 승인 후 시작한다.
