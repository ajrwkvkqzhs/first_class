# 원강금속 기준 디자인

준비 단계에서 현재 코드를 읽어 적은 기준선이다. Impeccable의 `document` 명령을 실행한 결과는 아니다.

## 현재 정체성

- 금속·주조 산업의 기술과 신뢰를 소개하는 한국어 B2B 기업 사이트.
- 원강금속 로고, Noto Sans KR, 흰색·회색 바탕, 빨강과 파랑 포인트.
- 주요 색상: 빨강 `#e60021`, 진한 빨강 `#b7001b`, 파랑 `#08337d`, 본문 `#161519`, 보조 글 `#626773`, 옅은 바탕 `#f7f8fa`.
- PC 80px·작은 화면 76px 헤더. 메뉴는 스크롤 방향과 마우스·키보드 접근에 반응한다.

## 기준 구성

히어로 → 사업 카드 3장 → 기업 실적 → 제품 CTA 4개 → 공정 갤러리 8개 → 인증서 11개 → 협력사 12개 → 사업장·푸터.

## 비교 시 개선할 수 있는 항목

- 한국어 사업명과 영문 제목의 위계, 설명 길이와 행간.
- 섹션 여백·콘텐츠 최대 너비·사진 비율·카드 크기.
- 반복 요소의 일관성, 버튼과 링크의 구분, 현재 위치와 이동 대상 표시.
- 헤더·하위 메뉴·CTA·갤러리·인증서의 시각적 연결과 반응형 균형.

## 자산 조건

현재 사업 카드 사진 세 장은 각각 350×141px다. 크게 배치할 때 흐릿함이 늘어나는 한계가 있다. 기존 이미지를 단순 확대해 고해상도 사진으로 표현하지 않는다. 회사와 무관한 사진을 실제 설비·제품처럼 쓰지 않는다.

현재 준비본은 이 디자인을 그대로 복사한 상태이며 아직 개선 결과를 적용하지 않았다.
