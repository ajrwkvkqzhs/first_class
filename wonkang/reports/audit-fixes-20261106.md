# 원강금속 사이트 오류 수정 — 2026-11-06

대상: https://first-class-site.pages.dev/wonkang/

## 확인한 문제와 수정

- 320px 화면에서 히어로 설명의 하단이 히어로 밖으로 약 23px 넘쳐 잘렸습니다. 모바일 컨트롤 높이를 내용에 맞추고, 제목의 위치도 실제 컨트롤 높이에 연동했습니다. 수정 후 설명 하단에 16px 여백, 제목과 컨트롤 사이에 25px 간격이 확보됩니다.
- 메인 제품 소개의 밸브부품에 단조재 문구, 고압펌프부품에 CASK 수출 문구가 섞여 있었습니다. 기존 제품 분류에 맞는 설명으로 4개 카드를 정리했습니다.
- 메인 제품의 자세히 보기가 같은 설명을 반복하는 팝업만 열었습니다. 이미 존재하는 4개 제품 상세페이지로 이동하는 기본 링크로 연결했습니다.
- 인증서가 첫 클릭에서는 선택만 되고 두 번째 클릭에서 확대되었습니다. 클릭·터치·키보드 실행 한 번으로 선택한 인증서를 확대하도록 수정했습니다. 모바일 초기 선택을 처음 표시되는 인증서와 맞추고, 화면 크기가 바뀌어도 선택한 인증서가 목록 안에 보이도록 했습니다.

## 검증

- Chrome 실제 브라우저에서 320×568, 360×800, 390×844, 768×1024, 1440×900 화면을 확인했습니다. 가로 넘침이나 히어로 설명 잘림이 없고 제목과 컨트롤 간격이 유지됩니다.
- 인증서 한 번 클릭 확대, 선택한 인증서와 팝업 내용 일치, Escape 닫기와 포커스 복귀, End 키로 마지막 인증서 선택을 확인했습니다.
- 메인 고압펌프부품 링크가 실제 상세페이지로 이동하는 것을 확인했습니다. 모바일 메뉴 열기와 하위 메뉴 확장도 확인했습니다.
- 기존 정적 경로 검사 로직으로 17개 페이지, 로컬 참조 1,095개, 앵커 123개, CSS 자산 14개, JavaScript 4개의 경로·구문 오류가 없음을 확인했습니다. 변경한 테스트 파일 3개의 구문 검사와 git diff --check도 통과했습니다.
- 기존 브라우저 테스트의 제품 팝업 전제와 인증서 두 번 클릭 전제를 수정했습니다. Playwright 자동화 전체 실행은 하지 않았으며, 위 동작은 연결된 Chrome에서 직접 검증했습니다.

제품 도면·규격·카탈로그 원본이 없는 영역의 자료 안내는 유지했습니다.
