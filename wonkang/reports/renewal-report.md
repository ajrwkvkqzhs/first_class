## 30초 요약

피그마의 전체 메인페이지를 기준으로 누락된 하단 구역까지 구현했습니다. **PC 원본의 구성·색상·사진·간격을 유지하고 모바일에서도 읽고 조작할 수 있도록 조정했습니다.**

- **구현:** 헤더·히어로, 사업 소개 3개, 실적, 제품 4개, 공정 사진 8개, 인증서 11개, 협력사 12개, 푸터.
- **원본 자산:** 피그마 이미지·SVG 58개를 모두 로컬에 저장하고 실제 코드에서 사용했습니다.
- **검증:** 360·390·768·1024·1440·1920px, 이미지 로드 및 페이지 가로 넘침·JS 오류 검사 통과.
- **기능:** 메뉴, 히어로 전환, 제품 상세, 이메일·전화 문의, 인증서 선택·확대, 맨 위로 이동.
- **추가 자료:** 실제 카탈로그 파일과 정식 개인정보 취급방침 원문이 필요합니다. 해당 버튼에는 현재 요청·안내 화면을 연결했습니다.

## 판단해서 적용한 개선

1. **모바일 재배치:** PC를 그대로 축소하면 글자가 너무 작아져, 600px 이하에서 사업·제품·공정은 1열, 로고는 2열로 배치했습니다. 인증서는 가로로 넘기며 전체 종이를 볼 수 있습니다.
2. **실제로 반응하는 버튼:** 클릭 효과만 있던 메뉴와 제품 버튼을 섹션 이동과 제품 상세로 연결했습니다. 문의는 피그마에 기재된 영업소 메일·전화로 연결합니다.
3. **접근성:** 본문 바로가기, 버튼 이름, 메뉴 열림 상태, 인증서 키보드 선택, 팝업의 Escape·닫기·포커스 복귀를 적용했습니다.
4. **안정적인 자산:** 임시 외부 이미지와 누락된 fallback 경로를 제거하고 피그마 원본을 로컬에서 불러옵니다. 원본 SVG의 내부 경로와 크기 속성은 수정하지 않았습니다.
5. **타이포그래피:** 기존 Noto Sans KR Regular·Medium·Bold를 재사용하고 Light를 추가해 공정 갤러리의 얇은 영문 글씨를 맞췄습니다.
6. **작은 문구 정리:** 명백한 오타인 ‘요굳회는’, ‘급속 소재’, ‘PRECISON’을 ‘요구되는’, ‘금속 소재’, ‘PRECISION’으로 정리했습니다. 별도 뉴스 페이지가 없는 메인 범위에서 ‘회사 소식’은 ‘주요 실적’ 또는 ‘주요 성과·인증’으로 연결했습니다.

## 추가 자료 및 남은 운영 연결

- **카탈로그:** 원본 파일이 없어 다운로드를 가장하지 않고 요청 안내와 이메일·전화 연결을 제공했습니다.
- **개인정보 취급방침:** 정식 원문을 제공받지 않아 임의의 정책을 만들지 않고 문의 안내를 제공합니다.
- **실적·인증서·제품 문구:** 피그마에 담긴 자료를 유지했습니다. 회사의 최신 수치, 인증 유효성, 제품 설명의 사실 여부를 별도로 확인한 것은 아닙니다.
- **하위 페이지:** 이번 디자인은 메인페이지입니다. 메뉴는 메인의 관련 구역으로 연결하고 제품은 상세 팝업을 제공합니다. 회사 연혁·뉴스·CI 가이드 같은 별도 상세 페이지는 제작 범위에 포함하지 않았습니다.
- **배포:** 최초 구현 PR #3을 main에 병합해 GitHub Pages에 배포했습니다. [공개 사이트](https://ajrwkvkqzhs.github.io/first_class/wonkang/)에서 확인할 수 있습니다. 이후 인터랙션 요청은 같은 사이트에 이어서 반영합니다.
