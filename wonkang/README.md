# 원강금속 리뉴얼 시안

HTML, CSS, JavaScript로 구성한 기업 검토용 메인 및 제품 카탈로그입니다. 빌드나 패키지 설치가 필요하지 않습니다.

저장소 루트를 정적 서버로 열고 `/wonkang/index.html`에 접속합니다. 기존 루트 `index.html`의 **개선된 원강금속 웹사이트** 링크로도 진입할 수 있습니다. `font/` 폴더를 포함한 저장소 상대 경로를 유지해야 합니다.

## 화면과 동작

- `index.html`: 스크롤 반응형 히어로, 회사소개와 성과, 네 제품군 선택, 다섯 장면의 생산공정, 인증자료 확대, 파트너, 연락처.
- `catalog.html`: 기존 네 제품군 해시 주소를 유지하는 상세 소개와 고정 제품군 메뉴.
- `css/style.css`: 공통 브랜드 변수, 반응형 배치, 모션 감소 및 인쇄 스타일.
- `js/main.js`: 메뉴, 제품 탭의 방향키·Home·End 조작, 스크롤 장면, 현재 위치 표시, 인증서 네이티브 대화상자.

생산공정 고정 연출은 폭 1024px 이상·높이 760px 이상이며 모션 감소 설정이 꺼져 있을 때 활성화됩니다. 그 외에는 다섯 장면을 일반 문서 흐름으로 표시합니다. JavaScript 없이도 제품·공정 내용과 카탈로그·인증자료 링크를 이용할 수 있습니다.

이메일 링크는 제품명과 문의 준비 항목을 입력한 메일 작성 화면을 엽니다. 서버로 문의를 저장하거나 자동 발송하지 않습니다.

## 공식 자료

2026-10-15에 확인한 원강금속 공식 공개 자료를 기반으로 구성했습니다.

- 기업 소개·공개 실적·연락처: https://wks2025.mycafe24.com/
- 로고·브랜드 색상: https://wks2025.mycafe24.com/page/page0103.php
- 생산공정: https://wks2025.mycafe24.com/page/page0201.php
- 인증서: https://wks2025.mycafe24.com/bbs/board.php?bo_table=cert

공식 8개 공정을 `검토·목형 → 주입 → 열처리·후처리 → 3D스캔·가공 → 검사`의 5장면으로 묶었습니다. 사진은 각 장면에 해당하는 공식 공정 자료입니다. 인증서는 공식 공개 이미지를 사용하며 현재 유효성이나 별도 제작 사양을 임의로 보증하지 않습니다.

`assets/sources.json`에 각 이미지 원본 주소와 최적화 파일 크기를 기록했습니다. 로컬 WebP 자산을 사용하므로 외부 이미지 호스팅 상태가 화면 로딩에 영향을 주지 않습니다. 기존 Pretendard 폰트와 폰트 CSS를 재사용합니다.
