# 원강금속 — 원본 및 구조 유지 개선본

루트 `index.html`에서 두 버전을 각각 열 수 있습니다.

- **원강금속 리뉴얼 메인페이지** → `wonkang/index.html` (기존 초안)
- **개선된 원강금속 웹사이트** → `wonkang/improved.html` (첨부한 레이아웃을 유지한 개선본)

원본의 `index.html`, `catalog.html`, `css/style.css`, `js/main.js`는 기존 main 브랜치의 파일을 그대로 보존합니다. 개선본은 원본 CSS를 재사용하고 `css/improved.css`, `js/improved.js`로 스타일과 동작을 보강합니다. 개선본 카탈로그는 `catalog-improved.html`입니다. 프레임워크나 빌드는 필요하지 않습니다.

## 유지한 화면 구조

1. 상단 로고·메뉴·언어·기술문의·견적문의와 대형 현장 사진
2. 테두리 없이 본문 폭을 채우는 회사소개 세로 아코디언 5개, 아래 현장 이미지와 중앙 메시지
3. 흰 배경의 기업 성과 숫자 (위 2개, 아래 1개)
4. 대표제품 4개 카드와 고객문의·카탈로그 버튼
5. 이미지와 텍스트를 좌우 교차 배치한 생산·기술 콘텐츠
6. 실제 A4 인증서 8장이 겹쳐 있다가 순차적으로 펼쳐지는 가로 배열
7. 원색 원형 파트너 로고 5개 × 2줄, 좌측 대형 기업 메시지와 우측 문의 링크, 회색 푸터

## 보강한 인터랙션

- 상단 메뉴에 포인터·키보드로 접근하면 3열 하위 메뉴를 표시합니다. 모바일 메뉴는 별도 열기·닫기와 Esc를 지원합니다.
- 회사소개 전체가 화면 높이 안에 들어가면 자연스러운 스크롤에 맞춰 아코디언을 순차 전환합니다. 904px 폭을 포함해 화면의 실제 여유 높이로 판단하며, 제목 버튼으로 직접 선택할 수 있고 휠·터치의 기본 동작을 막지 않습니다.
- 첫 화면 사진의 확대율과 문구 이동, 회사소개 이미지 펼침·문구 순차 등장·진행선, 성과 숫자 등장, 4개 제품 카드의 순차 등장과 버튼 노출, 기존 좌우 교차 공정의 이미지·텍스트 등장과 사진 패럴랙스를 적용했습니다.
- 인증서는 섹션 진입 시 문서별 시차를 두고 펼쳐집니다. 호버·포커스로 선택한 문서를 앞으로 꺼내고 방향키로 탐색할 수 있습니다. 좁은 화면에서는 가로로 넘겨보며 링크를 열면 해당 공식 인증자료 상세로 이동합니다.
- 파트너 로고의 원래 색상과 위치를 유지합니다. 호버·포커스 시 원형 선을 따라 강조가 그려지고 회사명이 나타납니다. 흑백 전환과 위로 뜨는 효과는 사용하지 않습니다.
- 화면 높이가 부족하거나 모션 감소 설정이면 회사소개 고정을 해제합니다. JavaScript가 없을 때도 회사소개 전체와 본문 정보를 읽을 수 있습니다.
