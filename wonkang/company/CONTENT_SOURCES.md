# 원강금속 회사소개 서브페이지 — 콘텐츠 근거 및 디자인 확장 기록

> 범위: `company/about.html`, `company/about.css`, `company/about.js`
> 이 문서는 학습·검증을 위한 작업 기록입니다. 웹페이지의 UI 링크는 리뉴얼 저장소 내부 경로·전화 연결만 사용합니다.

## 정보구조를 이렇게 바꾼 이유

기존 예시 '비주얼 / 브레드크럼 / 브랜드 스토리 / 브랜드 가치 / 브랜드 역사'를 기계적으로 복제하지 않았습니다.
산업용 금속 부품을 구매·조달·검토하는 B2B 방문자가 기업의 실체를 확인하는 흐름을 우선했습니다.

1. 비주얼: 방문 페이지와 금속 제조업 정체성 인식.
2. 브레드크럼 + 섹션 목차: 현재 위치 및 상세 정보 접근성 확보.
3. 기업 개요: 기업이 무엇을 제조하며 어느 분야에 공급하는지 설명.
4. 제조 역량: 주조·정밀 가공·품질 관리가 어떻게 연결되는지 설명.
5. 품질·협력: 추상적 강점 대신 인증서 원본 이미지와 파트너 로고 활용.
6. 핵심 가치: 실제 공개된 Innovation / Partnership / Reliability / Ambition 정리.
7. 연혁: 출처가 확인된 주요 이정표만 선별.
8. 문의: 기존 리뉴얼 메인페이지의 연락처로 연결.

## 사실 확인 출처

- 기업의 1988년 원강기계 설립, 1996년 법인 전환, 2010년 홍성 이전과 ISO 9001, 2011년 수출의 탑/JIS, 2017년 벤처기업/NORSOK, 2025년 KIMS 패밀리기업 및 글로벌강소기업 1,000+ 선정 기록: [원강금속 연혁 영문 페이지](https://wks2025.mycafe24.com/bbs/board.php?bo_table=history_en)
- 공정과 사업 소개, 회사의 네 가지 가치(Innovation, Partnership, Reliability, Ambition): [원강금속 공개 홈페이지](https://wks2025.mycafe24.com/)
- 제품 카테고리·품질 인증 이미지·협력사 로고 및 메인 디자인 재사용 근거: `../index.html`, `../img/figma/`, `../css/main.css`.
- 현 홈페이지의 일부 영역은 임시 텍스트가 남아 있으며 통계·성과 수치는 갱신 가능성이 있으므로, 근거가 불충분한 수치와 '아시아 최초' 등의 비교·최상급 표현은 이 페이지에 넣지 않았습니다.
- 인증서·파트너 이미지는 저장소에 존재하고 메인페이지에 사용된 파일이며, **현재 인증의 유효기간이나 계약 관계까지 독립적으로 검증했다는 뜻은 아닙니다.**

## Design.md를 확장한 근거

| 메인 / 문서 기준 | 서브페이지 적용 |
| --- | --- |
| `--primary-default`, `--primary-hover` | 키커·구분선·문의 CTA·호버 |
| `--brand-blue`, `--brand-neutral-950` | 연혁·기업가치 배경에 활용 |
| `Noto Sans KR` 및 대형 산업형 제목 | 서브페이지 타이포그래피 계층 |
| `site-header`, `site-nav`, `site-footer` | 마크업·스타일·동작 유지 |
| 산업 사진과 명암 오버레이 | 제조 현장 이미지 기반 서브 비주얼 |
| Grid/Flex와 기존 1700/1100/850/600 분기 | 단계별 레이아웃 변경 |
| 메인 사업/공정 이미지 배치 | 제조 역량 3단계 정보형 레이아웃 |
| 기존 이미지 폴더 | 인증서 및 파트너 로고 재사용 |
