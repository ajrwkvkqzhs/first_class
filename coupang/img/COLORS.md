# 쿠팡 UI 색상 기준

- 주요 색상: `#0088FF`
- 밝은 배경 / 흰색: `#FEFEFE`
- 글자 / 검정: `#000000`

이 값은 사용자가 지정한 컬러 참고값입니다. HTML/CSS에는 아직 적용하지 않았습니다.

## 이미지 파일명

첨부 ZIP에 있는 화면 이미지 11개의 파일명을 `버거킹`에서 `쿠팡`으로 변경했습니다.
이 작업은 파일명만 변경한 것이며, PNG 이미지 내용은 그대로입니다.

이미지는 별도의 `쿠팡_UI_이미지_파일명수정.zip`으로 제공했습니다.
GitHub `coupang/img/`에는 현재 이 컬러 기록 파일만 반영되어 있습니다.
