# 쿠팡 모바일 디자인 스타일 20종

## 진입 경로

- 저장소 루트 `index.html` → `coupang/themes/index.html` → `theme-01.html` ~ `theme-20.html`.
- 각 디자인은 개별 HTML 파일과 공통 `themes.css`, `themes.js`를 사용합니다.
- 원본: `coupang/login.html`, `coupang/login.css`, `coupang/login.js` — 수정하지 않습니다.

## 사용 방법

테마 목록의 카드 클릭 또는 화면 상단의 이전/다음 화살표로 20개 스타일을 이동합니다.
각 페이지에서 로그인, 아이디 찾기, 비밀번호 재설정, 회원가입 화면을 전환하고 입력값 검증을 테스트할 수 있습니다.
실제 쿠팡 계정 로그인, 비밀번호 변경, 본인인증, SNS 인증 API는 연결되지 않습니다.
